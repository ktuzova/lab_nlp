# Лабораторная работа №2: NLP (задание на тройку)

## Описание

Инференс модели Qwen2.5:0.5B на сервере Ollama. Скрипт отправляет 10 запросов к LLM через HTTP API и формирует отчёт.

## Стек

- Python 3.10+
- Ollama
- Qwen2.5:0.5B

## Установка и запуск

### 1. Установить Ollama

Скачать и установить с [ollama.com](https://ollama.com/).

### 2. Скачать модель

```bash
ollama pull qwen2.5:0.5b
```

### 3. Убедиться, что сервер Ollama запущен

Ollama автоматически запускается после установки и слушает на `http://localhost:11434`.

Проверка:

```bash
curl http://localhost:11434
```

Ожидаемый ответ: `Ollama is running`

### 4. Установить зависимости Python

```bash
pip install -r requirements.txt
```

### 5. Запустить скрипт инференса

```bash
python inference.py
```

### 6. Результат

После выполнения скрипта в корне проекта появится файл `report.md` — отчёт инференса с таблицей запросов и ответов LLM.

## Структура проекта

```
lab2-nlp/
├── README.md            # Документация и инструкция
├── requirements.txt     # Зависимости Python
├── inference.py         # Скрипт инференса
└── report.md            # Отчёт (генерируется скриптом)
```
